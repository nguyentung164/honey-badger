## 📝 Changelog / 変更履歴 / Thay đổi

### English (en)

chore: update version to 1.2.5 and add fetchRemoteBranch functionality
- Bumped version from 1.2.4 to 1.2.5 in package.json.
- Introduced fetchRemoteBranch function to fetch remote-tracking refs without affecting local branches.
- Updated IPC handlers and constants to support new fetchRemoteBranch functionality.
- Enhanced CommitWorkflow components with additional project selection and run choices summary features.
- Improved UI elements and translations for better user experience.
